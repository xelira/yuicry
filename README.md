# yuicry

Музыка без лишнего. Поиск по каталогу Deezer, звук через `yt-dlp`, «моя волна»
из твоих лайков.

Вход обязателен: без сессии сайт не отдаёт ни страницы, ни API.

## Что умеет

- **Поиск** по Deezer: название, исполнитель, обложки, длительность.
- **Моя волна** — 20 треков: 70% похожего на лайки, 30% из самих лайков.
  Скипнутые треки в выборку не попадают.
- **Избранное** хранится в аккаунте, с поиском по названию и исполнителю.
- **Альбомы** — свои подборки; трек добавляется из поиска или избранного, без
  запуска воспроизведения.
- **Повтор**: выключен, вся очередь или один трек. Дизлайк убирает трек из волны
  и сразу включает следующий.
- **Две темы**, светлая и тёмная, переключаются в меню профиля и запоминаются.
- **Полноэкранный плеер**: клик по обложке открывает трек на весь экран; фон
  перекрашивается по палитре обложки и реагирует на бас, середину и верхние
  частоты.
- **Плеер** внизу: перемотка, громкость, скорость 0.5–2x, кнопки на наушниках и
  экране блокировки через `navigator.mediaSession`.
- **Очередь** — в меню «⋮»: горизонтальная лента обложек, сначала четыре, дальше
  остальные.
- **Клавиатура**: пробел — пауза, ←/→ — переключение, `/` — поиск.
- **Автоподгрузка**: когда в очереди остаётся меньше трёх треков, волна
  дособирается сама.
- **Возврат к месту**: после перезагрузки страницы восстанавливаются последний
  трек и позиция в нём.

## Как устроено

```
браузер
  │
  ▼
сервер ── статика Next.js
  └── /api ── JSON и аудио
        │
        └── gRPC ── хранилище на отдельной машине
```

Скачивание идёт на машине с доступом к YouTube, файлы хранятся на другом
сервере и отдаются оттуда.

- **HTTP Range** — перемотка не требует заново скачивать трек.
- **singleflight** — два одновременных запроса одного трека дают одно скачивание.
- **Ротация кэша** — при переполнении хранилища удаляются самые старые файлы.

## Стек

| Слой | Чем |
|---|---|
| API | Go, `net/http`, SQLite (`modernc.org/sqlite`) |
| Хранилище | gRPC между серверами |
| Фронтенд | Next.js App Router, TypeScript, Tailwind, zustand |
| Звук | `yt-dlp`, `deno` для challenge, каталог Deezer |
| Вход | OwaID, OIDC с PKCE, публичный клиент без секрета |

## Android

Сборка в `android/` — нативная обёртка WebView, без сторонних зависимостей.

```bash
cd android && ./gradlew assembleDebug
```

APK приложен к релизу. Подпись отладочная: для магазина нужен свой keystore и
`assembleRelease`.

## API

| Метод | Путь | Что отдаёт |
|---|---|---|
| `GET` | `/api/search?q=` | треки из Deezer |
| `GET` | `/api/stream/{id}` | аудио, Range |
| `POST` | `/api/reaction` | лайк, снятие лайка, дизлайк, скип |
| `GET` | `/api/wave` | 20 треков волны |
| `GET` | `/api/similar/{id}` | похожие треки |
| `GET` | `/api/likes` | избранное с метаданными |
| `GET` | `/api/albums` | альбомы с обложками |
| `POST` | `/api/albums` | создать альбом |
| `GET` | `/api/albums/{id}` | треки альбома |
| `POST` | `/api/albums/{id}/tracks` | добавить трек |
| `DELETE` | `/api/albums/{id}/tracks/{track}` | убрать трек |
| `GET` | `/api/me` | имя и аватар |
| `GET` | `/api/health` | проверка живости |

Всё, кроме `/api/auth/*`, `/api/health` и `/login`, требует сессии: `401` для API
и `302` на вход для страниц.
