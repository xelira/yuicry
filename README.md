# yuicry

Музыка без лишнего. Поиск по каталогу Deezer, звук через `yt-dlp`, «моя волна»
из твоих лайков.

Вход обязателен: без сессии сайт не отдаёт ни страницы, ни API.

## Что умеет

- **Поиск** по Deezer: название, исполнитель, обложки, длительность.
- **Моя волна** — 20 треков: 70% похожего на лайки, 30% из самих лайков.
  Скипнутые треки в выборку не попадают.
- **Избранное** хранится в аккаунте, с поиском по названию и исполнителю.
- **Плейлисты** — свои подборки; трек добавляется из поиска или избранного, без
  запуска воспроизведения.
- **Повтор**: выключен, вся очередь или один трек. Дизлайк убирает трек из волны
  и сразу включает следующий.
- **Две темы**, светлая и тёмная, переключаются в меню профиля и запоминаются.
- **Полноэкранный плеер**: клик по обложке открывает трек на весь экран; фон
  перекрашивается по палитре обложки и реагирует на бас, середину и верхние
  частоты.
- **Плеер** внизу: перемотка, громкость, скорость 0.5–2x, кнопки на наушниках и
  экране блокировки через `navigator.mediaSession`.
- **Очередь** — в меню «⋮»: горизонтальная лента обложек, сначала четыре, дальше
  остальные.
- **Клавиатура**: пробел — пауза, ←/→ — переключение, `/` — поиск.
- **Автоподгрузка**: когда в очереди остаётся меньше трёх треков, волна
  дособирается сама.
- **Возврат к месту**: после перезагрузки страницы восстанавливаются последний
  трек и позиция в нём.
- **Синхронизация между устройствами**: трек повторяется на других устройствах
  аккаунта с той же позицией; второе устройство играет без звука, пока звук не
  включат вручную. Обновления приходят по SSE, без опроса раз в 4 секунды.
- **Уведомление в Android**: обложка, название, исполнитель, остаток времени,
  перемотка, пауза, назад, вперёд и лайк прямо из шторки; разрешение на
  уведомления спрашивается при первом воспроизведении.
- **Доступ из РФ**: обложки и звук идут через сервер, поэтому блокировки
  внешних CDN не мешают каталогу и воспроизведению.

## Как устроено

```
браузер
  │
  ▼
сервер ── статика Next.js
  └── /api ── JSON и аудио
        │
        └── gRPC ── хранилище на отдельной машине
```

Скачивание идёт на машине с доступом к YouTube, файлы хранятся на другом
сервере и отдаются оттуда.

- **HTTP Range** — перемотка не требует заново скачивать трек.
- **singleflight** — два одновременных запроса одного трека дают одно скачивание.
- **Очередь загрузок** — не больше трёх `yt-dlp` одновременно.
- **Кеш Deezer** — поиск и волна кешируются на 5 минут, ошибки повторяются.
- **Кеш обложек** — 512 МБ на диске, браузер получает `immutable`.
- **Ротация кэша** — при переполнении хранилища удаляются самые старые файлы.

## Стек

| Слой | Чем |
|---|---|
| API | Go, `net/http`, SQLite (`modernc.org/sqlite`) |
| Хранилище | gRPC между серверами |
| Фронтенд | Next.js App Router, TypeScript, Tailwind, zustand |
| Android | Capacitor 8, WebView, foreground-служба для звука |
| Звук | `yt-dlp`, `deno` для challenge, каталог Deezer |
| Вход | OwaID, OIDC с PKCE, публичный клиент без секрета |

## Тесты

```bash
make test
```

- `backend` — формат аудио, «Моя волна», подписи сессий, хранилище, состояние
  воспроизведения, кеш обложек и Deezer, SSE-хаб.
- `frontend` — Vitest: очередь, повтор, лайки, дизлайк, догрузка волны.
- `frontend` — Playwright: запуск волны, лайк, поиск и воспроизведение.

## Сборка и деплой

```bash
make build      # API и статика
make deploy     # тесты, сборка, отправка на сервер, рестарт
make apk        # debug APK
```

`make deploy` по умолчанию использует `HOST=finland`.

## Android

Сборка в `frontend/android` на Capacitor 8. Приложение не хранит копию сайта:
WebView открывает живой интерфейс, а нативная часть отвечает за системные панели,
тему, безопасные отступы и фоновое воспроизведение.

```bash
make apk
```

Нужны JDK 21 и Android SDK 36. Для релизной подписи задай `YUICRY_KEYSTORE`,
`YUICRY_KEYSTORE_PASSWORD`, `YUICRY_KEY_ALIAS`, `YUICRY_KEY_PASSWORD` и собери
`./gradlew assembleRelease` или `make release-apk`. В GitHub Actions те же
значения лежат в секретах `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.

## API

| Метод | Путь | Что отдаёт |
|---|---|---|
| `GET` | `/api/search?q=` | треки из Deezer |
| `GET` | `/api/stream/{id}` | аудио, Range |
| `POST` | `/api/reaction` | лайк, снятие лайка, дизлайк, скип |
| `GET` | `/api/wave` | 20 треков волны |
| `GET` | `/api/similar/{id}` | похожие треки |
| `GET` | `/api/likes` | избранное с метаданными |
| `GET` | `/api/albums` | плейлисты с обложками |
| `POST` | `/api/albums` | создать плейлист |
| `GET` | `/api/albums/{id}` | треки плейлиста |
| `POST` | `/api/albums/{id}/tracks` | добавить трек |
| `DELETE` | `/api/albums/{id}/tracks/{track}` | убрать трек |
| `GET` | `/api/me` | имя и аватар |
| `GET` | `/api/playback` | состояние воспроизведения |
| `POST` | `/api/playback` | обновить состояние |
| `GET` | `/api/playback/stream` | SSE с состоянием воспроизведения |
| `GET` | `/api/health` | проверка живости |

Всё, кроме `/api/auth/*`, `/api/health` и `/login`, требует сессии: `401` для API
и `302` на вход для страниц.
