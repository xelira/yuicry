# Security policy

## Versions

No releases yet. `main` is the supported branch. Tagged versions get listed here when
they exist.

## Reporting

Do not open a public issue, pull request or discussion. Report privately:

- GitHub private advisories:
  <https://github.com/xelira/yuicry/security/advisories/new>
- If that page is unavailable: noreply@owaw.online, subject `yuicry security`.

Include:

- the affected version, tag or commit;
- what breaks and what an attacker gains from it;
- steps to reproduce, plus a proof of concept if you have one;
- a proposed fix, if you have one.

## Timelines

- Acknowledgement within 72 hours.
- Assessment within 7 days.
- A fix or a written mitigation plan.
- Coordinated disclosure. The default embargo is 90 days from the report, shorter if a
  fix ships first or the issue is already public.
- Credit in the advisory, unless you ask to stay anonymous.

## Scope

This repository and releases published from it. Forks belong to their maintainers.
Reports that need an already compromised environment are out of scope.

## Safe harbour

No legal action against researchers who stay in good faith: no privacy violations, no
data destruction, no service disruption; report privately and wait for the fix before
publishing; stop at the proof of concept.
