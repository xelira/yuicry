# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.3.2] - 2026-11-14

### Changed

- время в плеере показывается как «прослушано / осталось», без минуса
- остаток в уведомлении тоже без минуса
- карточка волны использует ту же палитру, что и фон
- версия APK 1.3.2

## [1.3.1] - 2026-11-14

### Fixed

- аватар OwaID грузится через серверный прокси и больше не блокируется CSP
- классы прозрачности Tailwind (`bg-accent/80`, `bg-bg/70`) снова работают
- предзагрузка следующего трека не конкурирует с текущим

### Changed

- светлая тема стала насыщеннее, карточка волны получила эквалайзер и подсказку
- кнопка «Текст» теперь на обложке, если текст найден
- нижний блок полноэкранного плеера поднят выше
- версия APK 1.3.1

## [1.3.0] - 2026-11-14

### Added

- тексты песен через LRCLIB с подсветкой текущей строки и перемоткой по клику
- переименование плейлиста и выбор обложки из его треков
- «Показать ещё» в поиске, следующие 30 треков
- проверка обновлений APK и плашка со ссылкой на скачивание
- кеш аудио в браузере и предзагрузка следующего трека
- версионные миграции базы
- error boundary с кнопкой перезагрузки
- доступность: подписи мобильного меню, `focus-visible`, `aria-live`
- ежедневный бэкап базы и резервная копия ключа подписи

### Changed

- Three.js грузится лениво: первый экран 128 КБ вместо 261 КБ
- версия APK 1.3.0

## [1.2.0] - 2026-11-13

### Added

- синхронизация устройств через SSE вместо опроса раз в 4 секунды
- Vitest для состояния плеера и Playwright для основных сценариев
- CI: тесты Go, сборка фронтенда, E2E и debug APK
- релизная подпись APK и workflow публикации по тегу

### Changed

- `Player.tsx` разбит на хуки и компоненты
- кеш Deezer на 5 минут с повторами при ошибках
- кеш обложек на 512 МБ и `immutable` в браузере
- очередь загрузок `yt-dlp` ограничена тремя
- nginx сжимает ответы и отдаёт заголовки безопасности
- API получил таймауты и graceful shutdown

### Fixed

- обход проверки хоста обложек через домен вида `evildzcdn.net`
- ошибка загрузки трека теперь показывает сообщение и включает следующий
- версия APK 1.2.0

## [1.1.4] - 2026-11-13

### Added

- запрос разрешения на уведомления при первом воспроизведении
- медиауведомление: обложка, название, исполнитель, пауза, назад, вперёд и лайк
- команды из уведомления управляют плеером в приложении

### Fixed

- обложки загружаются через сервер, поэтому каталог работает из РФ
- уведомление не пропадает при паузе и обновляет состояние

### Changed

- обложки отдаются сжатыми под размер элемента: 120, 250 или 500 px
- версия APK 1.1.4

## [1.1.3] - 2026-11-13

### Changed

- Android-приложение переведено на Capacitor 8
- системные панели, тема и безопасные отступы управляются через Capacitor
- версия APK 1.1.3

### Fixed

- вход через OwaID снова работает в приложении
- сессия сохраняется между запусками
- фоновое воспроизведение подтверждено на эмуляторе

## [1.1.2] - 2026-11-13

### Fixed

- рывки звука: WebAudio-анализатор убран из аудиотракта
- фон приложения продолжается под системными панелями Android
- прокрутка только внутри раздела, без прокрутки страницы и пустых экранов
- полноэкранный плеер учитывает вырез камеры и панель навигации

### Changed

- синтетическая визуализация уровня вместо анализа реального звука
- метаданные Media Session для фонового воспроизведения в браузере
- версия APK 1.1.2

## [1.1.1] - 2026-11-13

### Added

- синхронизация воспроизведения между устройствами аккаунта
- фоновое воспроизведение в Android-сборке через foreground-службу
- тесты Go для API, синхронизации и файлового хранилища

### Changed

- мобильный плеер: play строго по центру, лайк у левого края, «похожие» у правого
- «Альбомы» переименованы в «Плейлисты», добавлен поиск по избранному

### Fixed

- системные панели Android больше не перекрывают интерфейс
- рывки звука при скрытом приложении или браузере
- кеширование страницы в APK отключено
